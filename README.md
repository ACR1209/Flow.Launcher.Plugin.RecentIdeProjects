# Recent IDE Projects (Flow Launcher)

Lists recent **VS Code** and **Zed** projects, including WSL and SSH remotes, and lets you star them.

- Keyword: `ide [filter words]`
- Enter opens the project in its IDE.
- Shift+Enter → Star / Unstar. Starred projects sort first.

Requires Python. Stdlib only.

Limits: Zed docker remotes skipped; VS Code Insiders not scanned.
